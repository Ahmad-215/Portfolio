# 🚀 Full-Stack Personal Portfolio Website

A modern, highly responsive, and interactive personal developer portfolio built with **HTML5, CSS3, and JavaScript**. Designed with custom smooth scrolling, animated section overlays, interactive cards, and a sleek dark theme aesthetic.

## 🌟 Key Features

- 🎨 **Modern Glassmorphism Design:** Dark-themed UI with glass-panel cards and glowing accents.
- 📱 **Fully Responsive:** Smoothly adapts across desktops, tablets, and mobile devices.
- ⚡ **Interactive Animations:** Dynamic scroll cue, rotating image rings, and scroll-triggered section animations.
- 🤖 **AI-Powered Workflow Section:** Highlighting accelerated web development capabilities using modern AI.
- 💼 **Why Choose Me Showcase:** Clear value-driven insights for clients and recruiters.
- 🔝 **Smooth Back-to-Top Navigation:** Dynamic floating scroll-to-top button.

---

## 🛠️ Tech Stack & Tools

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling Features:** CSS Variables, Flexbox, Grid, Keyframe Animations
- **Icons:** Font Awesome 6.x
- **Deployment:** Vercel / GitHub Pages
